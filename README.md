# ConvertCraft

Offline file conversion for macOS and Windows.

**This repository contains installer information and binary releases only. Application source code is private.**

## Download

Open [the latest release](https://github.com/CharisChristodoulakis/ConvertCraft/releases/latest) and download the installer for your computer:

- Apple Silicon Mac: the ARM64 `.dmg`
- Windows x64: the `.exe` installer

The installers are unsigned. If you currently have 0.1.0, install the latest version manually once. From 0.1.1 onward, the app can check this repository for new releases and offer to open a verified installer.

## Source archives

GitHub automatically offers ZIP and TAR source archives for this public repository. They contain this installer documentation, **not the application source code**.
